1. Fetch

The CPU uses the Program Counter to find the next instruction in RAM and loads it into the Instruction Register.

2. Decode

The Control Unit interprets the instruction and determines what operation and data are required.

3. Load Data

The required values are transferred from RAM into CPU registers.

4. Execute → 5. Store

The ALU performs the calculation. The result is then sent back to memory for storage.

Example: ADD R1, R2 → 5 + 7 = 12
